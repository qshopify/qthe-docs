## Accessibility built in

- Every interactive element can be reached and used with a keyboard, with a visible focus outline.
- A *Skip to content* link is the first thing keyboard users reach.
- Drawers, menus and dialogs trap focus while open and return it when closed.
- Preset color schemes meet WCAG AA contrast. Autoplaying slideshows and videos have pause controls and respect *reduce motion*.

**Your part:** write alt text for images (in **Content > Files** or on each product image), keep enough contrast if you change colors, and avoid putting essential text inside images.

## Performance built in

- Images are responsive and lazy-load below the fold; the first image loads with high priority.
- Videos load only when a shopper presses play.
- Scripts are small, load without blocking the page, and run only where a section needs them.

**Your part:**

- Upload images at a sensible size — around 2,400 px on the long side is plenty.
- Keep the home page to the sections that earn their place.
- Every app adds code. Remove apps you no longer use, and check their app embeds in **Theme settings > App embeds**.
