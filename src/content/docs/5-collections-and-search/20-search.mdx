## Predictive search

As shoppers type in the header search, QThe suggests products, collections and journal articles, plus related search terms. It uses Shopify's predictive search, so there's nothing to set up.

## Search results page

Results are grouped into tabs — **All**, **Products**, **Journal** and **Pages** — with the same filters and sorting as collections. When nothing matches, shoppers see a helpful message and can try again from the same page.
